# Repository Overview

This repository contains the complete implementation of the **SmartReco Behavioral AI Recommendation Platform**.

The project demonstrates enterprise backend engineering by combining:

- Behavioral Event Tracking
- Semantic Search
- Retrieval-Augmented Generation (RAG)
- Agentic AI Recommendations
- Production Engineering Practices
- Modern Software Architecture
